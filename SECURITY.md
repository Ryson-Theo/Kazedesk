# Security Policy

## Supported versions

Security fixes are currently considered for the latest code on the default branch. There are no separately maintained release branches.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue or pull request.

If private vulnerability reporting is enabled for this repository, use **Security → Report a vulnerability** on GitHub. Otherwise, contact the repository maintainers privately through a contact channel listed on the repository or maintainer profile. Include the affected version or commit, steps to reproduce, and potential impact. Do not include real user data or secrets in the report.

Please allow maintainers reasonable time to investigate and coordinate a fix before public disclosure. This project does not currently publish a guaranteed response or remediation timeline.

## Scope notes

Kazedesk runs in the browser and stores workspace information in that browser's local storage. Do not use it to store credentials or highly sensitive information. Weather lookup, YouTube embeds, and other external resources are provided by third parties and are subject to their own security and privacy practices.
